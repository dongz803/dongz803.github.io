# 机械臂研究

这一部分是网站的重点，主要记录机械臂运动学、逆解算法、运动规划和抓取实验。

## 研究方向

### PyRoki

- 机械臂模型建立
- 数值逆运动学
- 目标位姿约束
- 求解精度与速度测试

### IKFast

- URDF 与机械臂模型准备
- 解析逆解生成
- MoveIt 求解器集成
- 多组逆解筛选
- 奇异位形与求解失败分析

### 抓取实验

- 抓取目标位姿生成
- 预抓取与抓取姿态
- 轨迹规划
- 夹爪控制
- 抓取执行与结果分析

### 运动规划

- MoveIt 配置
- 关节空间规划
- 笛卡尔空间规划
- 碰撞检测
- 轨迹执行
